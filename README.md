## 📖 Описание

**Server_sled** — это веб-приложение для образовательных учреждений, предназначенное для:

- 🔐 Аутентификации преподавателей и администраторов
- 👤 Регистрации студентов с использованием распознавания лиц
- 📊 Отслеживания посещаемости в реальном времени
- 🚫 Блокировки нежелательных приложений и веб-сайтов в локальной сети
- 📝 Логирования попыток нарушения политик доступа
- 🗓️ Управления расписанием групп
